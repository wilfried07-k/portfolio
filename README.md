# Portfolio (React + Vite, FR/EN)

```bash
npm install
npm run dev
```

Où modifier quoi :
- `src/data/profile.js` : nom, e-mail, GitHub, LinkedIn
- `src/data/projects.js` : tes projets (FR + EN)
- `src/data/skills.js` : tes compétences
- `src/i18n/translations.js` : tous les textes du site
- `src/styles.css` : couleurs et typographie (variables en haut du fichier)
